# claude-mods

Plugins for **Claude Code** and **Google Antigravity (agy)**, each written once with
[Bifrost](packages/bifrost/README.md): one `src/plugin.tsx` with state, logic and a React-like UI that
renders as a TUI pane in Claude Code and as the aux-pane webview in Antigravity.

| Plugin | What it does |
| --- | --- |
| [ref-pane](plugins/ref-pane) | A pane of `RV-1`/`FB-2`/`T-3`/`ADR-4` references from the model's answers or project docs, with the artifact section rendered as Markdown |
| [quote-comments](plugins/quote-comments) | Comment on text selected in the chat: quoted comments collect in a pane and are appended to your next message |

## Install

Claude Code:

```text
/plugin marketplace add gidragir/claude-mods
/plugin install <plugin>@claude-mods
```

Antigravity: `agy plugin install gidragir/claude-mods#release/<plugin>`.

Each plugin is released by CI to a `release/<plugin>` branch that holds the built plugin for both hosts.

## Layout

```
packages/bifrost/        the framework: core, components, Claude + agy adapters, test kit, CLI
plugins/<plugin>/
  src/plugin.tsx         definePlugin({ panes, commands, claude, config, ... })
  src/*.ts(x)            logic and components
  test/                  Bun tests; test/engine/*.ts run in the real engine (claude plugin test)
  skills/, rules/        Antigravity agent skills and rules
  dist/                  generated by `bifrost build`: the installable plugin for both hosts
templates/mod/           what `pnpm new` scaffolds
scripts/                 dev linking, checks, marketplace (plain Node, no deps)
```

## Develop

Requires [mise](https://mise.jdx.dev) (Node, pnpm, Bun from `mise.toml`) and the Claude Code CLI.

```bash
mise install && pnpm install
pnpm types:sync            # engine type declarations (not committed); needs a plugin loaded once
pnpm new my-plugin "what it does"
pnpm dev my-plugin         # build to dist and rebuild on save
bun test                   # framework and plugin tests, ~100 ms
pnpm check                 # per plugin: build, claude plugin validate, tsc, engine tests
pnpm lint                  # Biome
```

### Load your build

| Command | Loads `plugins/<plugin>/dist` into |
| --- | --- |
| `pnpm dev:link` | `claude` started from a terminal in this repo (`mise.local.toml`) |
| `pnpm dev:link:desktop` | every new Claude Desktop session (`~/.claude/settings.json` env, daily backup) |
| `pnpm dev:link:agy` | Antigravity (`~/.gemini/config/plugins/<plugin>` and `.../sidecars/<plugin>` junctions) |
| `pnpm dev:status` | shows all three, plus installed plugins with clashing names |

Keep `pnpm dev` running: Claude Code hot-reloads the rebuilt hooks module, and the agy pane process exits on
a rebuild so Antigravity restarts it with the new code. `dev:unlink`, `dev:unlink:desktop`, `dev:unlink:agy`
remove the links. Linking only adds: installed plugins, marketplaces and other plugin dirs are left alone.

For conventions and runtime rules see [AGENTS.md](AGENTS.md).

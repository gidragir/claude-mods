# Refs Pane Navigation

The `ref-pane` plugin resolves and displays artifact sections referenced in conversations (like code reviews `RV-1`, feedback items `FB-2`, tasklists `T-3`, or architectural decisions `ADR-4`).

## Surfacing Navigation Pills

When you or the user cite or discuss artifact references, or when the user wants to inspect resolved reference items, surface a clickable sidecar pill link:

[Refs Pane](sidecar://ref-pane/)

Clicking this pill will toggle and display the Refs Web UI in the Antigravity Auxiliary Pane.

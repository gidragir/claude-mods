# GEMINI.md

Notes for Google Antigravity (agy) and Gemini CLI in this repository. AGENTS.md (imported above) is the
reference. Framework work (`packages/bifrost`) follows `packages/bifrost/AGENTS.md` instead.

## How Antigravity sees a plugin

Every plugin is built by `bifrost build` into `plugins/<mod>/dist/`, which is a complete Antigravity plugin:

- `dist/plugin.json`: name, display name, description, version, suggested prompts (from `definePlugin`).
- `dist/skills/<mod>/SKILL.md` and `dist/rules/AGENTS.md`: copied from the plugin's `skills/` and `rules/`.
- `dist/sidecars/<mod>/sidecar.json` + `server.mjs`: the aux pane. One view per pane in `definePlugin`
  (the first at `/`, others at `/pane/<id>`), served by the generated, self-contained `server.mjs`.

Discovery: `.agents/plugins.json` lists the `dist` folders (regenerated by `pnpm marketplace`);
`pnpm dev:link:agy` junctions `~/.gemini/config/plugins/<mod>` → `dist` and
`~/.gemini/config/sidecars/<mod>` → `dist/sidecars/<mod>`.

## The pane

The pane is the same UI as the Claude Code pane: the server renders the plugin's components to HTML,
the page posts clicks and input back, and state changes push a redraw over SSE. Nothing about the pane
is written by hand: no `index.html`, no `server.mjs`, no vendored CSS. To change it, edit the plugin's
components in `src/` and rebuild (`pnpm dev <mod>` restarts the pane process on every build).

Contract kept by the generated server: loopback only, `ANTIGRAVITY_SIDECAR_WEB_PORT`, the
`ANTIGRAVITY_SIDECAR_UI_TOKEN` check on every route but `/preload.js`, `sidecar_sdk/preload.js` (or a
built-in stand-in), theme variables from `theme-change`, workspace folders as the plugin's `cwd`.

## In conversations

When citing artifacts or pointing the user at a pane, surface a pill:

```markdown
[Open Refs Pane](sidecar://ref-pane/)
```

## Commands

- `pnpm dev:link:agy [mod…]` / `pnpm dev:unlink:agy [mod…]`: link / unlink the built plugins.
- `pnpm dev <mod>`: rebuild on save (the pane restarts with the new build).
- `pnpm dev:status`: links (stale ones flagged) across Claude Code, Desktop and Antigravity.
- `bun test`, `pnpm check`, `pnpm lint`: as in AGENTS.md.
